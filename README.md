### RM Metalúrgica - Sitio Web Oficial

Bienvenido al repositorio oficial de la página web de RM Metalúrgica. Este proyecto fue diseñado y desarrollado con el objetivo de digitalizar la presencia de la empresa, exhibir su amplio catálogo de soluciones metalúrgicas y facilitar el contacto directo con futuros clientes. 

### Sobre el Proyecto

RM Metalúrgica es una empresa especializada en brindar soluciones a medida en hierro, acero y estructuras metálicas. Su web está pensada para ser un canal intuitivo y moderno que refleja la robustez y calidad de su trabajo diario. 

El sitio destaca las principales áreas de especialización del taller: 

* Muebles a Medida: Diseño de mobiliario de estilo industrial y residencial moderno.
* Construcciones Metálicas: Estructuras pesadas, tinglados, galpones y soportes edilicios.
* Trabajos Especiales: Herrería de obra, aberturas, rejas, portones y proyectos personalizados (de todo un poco).

### Desarrollo Orientado al Cliente (Feedback Continuo)

Una de las características más importantes de este proyecto fue su metodología de trabajo. El sitio web se construyó bajo un enfoque 100% colaborativo y centrado en el cliente: 

* Consultas Iterativas: Cada sección, paleta de colores, tipografía y flujo de navegación se consultó y validó de forma constante con el dueño de la metalúrgica.
* Diseño a Medida: Se priorizaron las necesidades reales de su negocio, modificando detalles estéticos y funcionales en tiempo real basándose en su feedback directo.
* Satisfacción Garantizada: Gracias a este ida y vuelta constante, el resultado final cumple con todas las expectativas estéticas y comerciales del cliente, quedando completamente a su gusto.

### Tecnologías Utilizadas

El proyecto fue desarrollado utilizando herramientas modernas para garantizar un rendimiento óptimo, accesibilidad y adaptabilidad móvil (Responsive Design): 

* Estructura y Maquetación: HTML5 / CSS3
* Estilos y Componentes: Bootstrap (o la librería utilizada para el diseño visual)
* Interactividad: JavaScript
